### 发现的功能缺陷（均未修复，待用户确认）
1. **shareApp 不恢复**：App.vue 调 `loadConfig()` 未传 `onConfigLoaded`，
   `config.share_app` 从不读回 `shareApp`（初值恒为 `'all'`）。重启后分享目标丢失。
2. **loadCustomApps() 启动期从未调用**：全项目仅在 `window.onCustomAppSelected`
   与 `removeCustomApp` 内调用。Android「历史应用」弹窗恒为空。
3. **useMemeData 少传两个参数**：App.vue 调 `useMemeData(config, safeUpdateConfig)`，
   未传 `searchKeyword` / `searchImages`，
   导致 `switchMode` 里「切模式后重跑搜索」分支死代码；搜索态下切模式会显示不符的图片。
4. **双 config 实例互相覆盖**：App.vue（useConfig）与 views/Settings.vue 各持有独立
   `config` ref。Settings 改的 color_mode/theme_style 写库后，App.vue 不知情；
   回到首页任意一次 `safeUpdateConfig`（切模式/切分组/调列数/开关拼音）会用旧值覆写回 DB。
5. **搜索框 Ctrl+V 误触**：`handleKeyDown` 挂在 window 且不判断事件来源，
   在搜索框粘贴文字会走 `handlePasteImage`。
6. **ContextMenu N 个全局监听**：每个实例都在 window 注册 `keydown` / `tauri-android-back`，
   图片网格有多少张图就有多少个。
7. **visibilitychange 移除失败**：App.vue onMounted 注册匿名闭包，
   onUnmounted 移除的是 `handleAppResume`（该引用从未注册）。
8. **FloatingSearchButton 边界常量错误**：JS 用 `btnSize = 56`，CSS 实际 42px。

### 已排除的怀疑
- `commands/image.rs` 两处 `copy_image`、`commands/clipboard.rs` 两处
  `paste_image_from_clipboard_raw`：均由 `#[cfg(target_os = "android")]` 区分，合法。
- `thumbnail_path` 未做 resolve：全项目写入恒为 NULL，前端会 fallback 到
  已 resolve 的 `image_path`，不影响显示。
- useConfig 与 App.vue 重复注册 resize/wheel/touchstart/touchmove：
  传入的是**同一个函数引用**，浏览器 addEventListener 自动去重，不会双倍触发。

## 第二轮：修复上述 8 项（用户确认「修吧」后执行）

改动文件：`src/App.vue`、`src/composables/useSearch.ts`、`src/views/Settings.vue`、

### 关键接线约定（后续改动别踩回去）
- **config 是双实例的**：App.vue（经 useConfig）与 views/Settings.vue 各持有独立 ref。
  Settings 每次 `update_config` 成功后必须 `window.dispatchEvent(new CustomEvent('configNeedsReload'))`，
  App.vue 侧由 `handleConfigNeedsReload` 监听并重新 `loadConfig()`。
  **新增任何 Settings 侧写配置的路径，都要补一次 notifyConfigChanged()。**
- **searchKeyword 由 App.vue 持有并注入 useSearch**（第 3 个参数 `externalKeyword`）。
  原因：`useMemeData` 切模式后要重跑搜索，而 `useSearch` 又依赖 `useMemeData` 的数据，
  两者初始化顺序互相牵制，只能由上层持有同一个 ref 打破。不要改回各自 new ref。
- **handleConfigLoaded 内部顺序不可调换**：必须先 `loadCustomApps()` 拿到历史应用列表，
  再赋值 `shareApp`，最后按列表校验包名是否仍存在。
- **ContextMenu 的全局快捷键是动态挂载的**（`watch(show)` → `bindGlobalKeys`），
  不是静态注册。列表里每张图一个实例，静态注册会退化成 O(n) 个 window 监听器。
- `FloatingSearchButton` 的 `btnSize` 常量必须与 CSS 里的 `.floating-search-btn`
  宽高一致（现为 42px），改 CSS 尺寸时务必同步这里。

### 踩坑记录
- 一度以为 App.vue 里有 `validateCurrentShareApp()`，实际不存在，是 `loadCustomApps`
  内部的内联逻辑，导致 TS2304。最终在 `handleConfigLoaded` 里内联了包名校验。
- `ContextMenu` 的 `show` 是**内部 ref 不是 prop**，误写成 `props.show` 报 TS2339。
