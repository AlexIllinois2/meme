# 2026-10-15 界面优化：图标补齐 / 美观度 / 整体和谐度

## 图标体系离线化（"图标不齐"的根因）
- 根因：`Icon.vue` 原先用 `@iconify/vue` 在线版，`ri:` 图标运行时请求 api.iconify.design，
  弱网/离线（Tauri 打包、Android WebView）下图标缺失且首次加载闪烁。
- 修复：新增 `src/icons/remix-icons.json`（114 个 Remix 图标子集，~30KB）+
  `src/icons/index.ts`（`addCollection` 注册）；`Icon.vue` 改导入 `@iconify/vue/offline`；
  `main.ts` 挂载前 `import "./icons"`。tsconfig 已开 resolveJsonModule，JSON 直接导入。

## 修正了一批根本不存在的图标名（此前渲染为空白）
- `chevron-right` → `arrow-right-s`（Remix 无 chevron 命名）；`x` → `close`；
  `label` → `price-tag-3`；`delete` → `delete-bin`；MDI 的 `replay` → `restart`。
- 涉及 Settings.vue / SettingsAbout.vue / App.vue 菜单项。

## App.vue 全面去除 MDI（var-icon）混用，统一为 Remix 图标
- 映射：magnify→search、checkbox-marked→checkbox-circle-fill、
  checkbox-blank-outline→checkbox-blank-circle-line、cog→settings-3、
  window-close→close、plus→add、check-circle→checkbox-circle-fill、folder→folder-3。
- 弹窗关闭按钮统一为 `.btn-icon` + `close`；添加图片占位改 `image-add`；
  窗口非活动占位的内联 svg 改 `pause` 图标。

## 主题变量补齐（ThemeProvider 六套主题）
- 新增 `--color-primary-rgb`、`--color-on-primary`、`--color-success/-light`、
  `--color-warning/-light`、`--color-danger/-light`。
- 修复大量引用未定义变量的样式：`--text-color`→`--color-text`、
  `--text-secondary`→`--color-text-secondary`、`--primary-color`→`--color-primary`。

## 经验
- Remix Icon 命名注意：无 chevron-*/x-*/label-*/link-*/copy-*/minus-*，

# 需求：商店版 / 开源版渠道区分

## 构建渠道机制（**默认开源版，商店版需显式加参数**）
- 新增 `src/utils/channel.ts`：`isStoreVersion` / `isOpenSourceVersion`。
  判断逻辑为 **白名单式**：`VITE_APP_CHANNEL === 'store' ? 'store' : 'oss'`，
  即不注入变量或取值异常时一律降级为开源版，防止误打包成商店版。
- Vite 模式文件：`.env.oss` / `.env.store`（Vite 自动加载 `.env.[mode]`，vite.config.ts 无需改动）。
  `.gitignore` 未排除 `.env*`，两个配置文件正常提交。
- 脚本：
  - 默认（开源版）：`bun run dev` / `bun run build` / `bun run tauri build` / `bun run android:build`
  - 商店版：`bun run dev:store` / `bun run build:store` / `bun run tauri:build:store` / `bun run android:build:store`
- `src-tauri/tauri.store.conf.json` 仅覆盖 `build.beforeBuildCommand` 为 `bun run build:store`；
  开源版不需要同名配置（走 tauri.conf.json 默认 `bun run build` 即可）。

## 渠道行为差异
- App.vue：协议弹窗初始化处加 `isStoreVersion &&`，开源版启动直接进主界面。
- SettingsAbout.vue：用户协议 / 隐私政策两行加 `v-if="isStoreVersion"`；
  开源版保留「开源地址」「支持一下」入口。协议视图本身保留（商店版仍用），仅入口隐藏。

## 其他改动
- 术语统一：「刷新数据」→「重建索引」（App.vue 菜单项 + useMemeData.ts / Settings.vue 对应 Snackbar 文案）。
  内部命令名 refresh_index / full_refresh 未动。隐私政策正文里的"刷新数据"未改（法律文本，待用户确认）。
- 版本号修复：根因是 Rust 端从未注册 `get_version` 命令，invoke 失败被 catch 吞掉，
  导致 SettingsAbout 恒显 v0.0.0。已在 lib.rs 增加命令返回 `env!("CARGO_PKG_VERSION")` 并注册，
  前端加空值保护避免非 Tauri 环境渲染出 "v"。
- 移除 SettingsAbout 的「支持平台：Linux (x86_64) / Android (aarch64)」块及 `.platform-info` 样式。
