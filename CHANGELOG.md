# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-05-28

### Added
- Initial release of 咪萌 (Meme Manager)
- Mode-group hierarchical meme organization system
- Keyword search with pinyin and acronym support
- Batch image operations (delete, move)
- Theme system (light, dark, follow-system)
- Clipboard image paste (desktop)
- Android support with floating search window
- Custom share app management
- Image gallery save support (Android)
- Keyboard shortcut: Ctrl+Wheel for grid adjustment
- Pinch-to-zoom grid scaling on mobile
